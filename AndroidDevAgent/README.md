# Android Dev Agent

基于AI的安卓开发助手，具备强大的安卓编程能力。

## 核心功能
- 智能代码生成（支持Kotlin/Java/XML）
- 实时代码解释与优化建议
- 项目架构设计指导
- 调试错误诊断与修复
- 一键编译与测试

## 技术栈
- Jetpack Compose (UI)
- MVVM架构
- Retrofit (网络请求)
- Room (本地存储)
- Hilt (依赖注入)
- Gradle构建系统

## 项目结构
```
AndroidDevAgent/
├── app/                    # 主应用模块
├── core/                   # 核心功能模块
├── features/               # 功能模块
├── agent/                  # AI Agent核心逻辑
└── build.gradle            # 根构建文件
```
